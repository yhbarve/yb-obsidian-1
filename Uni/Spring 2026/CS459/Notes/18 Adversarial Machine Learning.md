# Machine Learning Recap
- Machine learning models are learned parameterized functions. For large-scale models or commercial models, they are usually trained on extensive private data sets.
- There are three main forms of machine learning:
	- Supervised
	- Unsupervised
	- Reinforcement Learning
- - -
# Machine Learning as a Service (MLaaS)
- Data gathering and training process can get quite complex, expensive, and time-consuming.
- In particular, this is true for classification where labeling has to be done by humans manually.
- A solution to this is machine learning as a service (MLaaS).
- It offers models as a queryable black box service. For example, ChatGPT or Claude.
- It requires significant computing capabilities to provide accessible service.
- If frequent queries are necessary, it can become quite expensive for the user.
- Leads to issues related to model theft.
